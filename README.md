# Wizard Bet — Futuristic 100 Game Demo

A mobile-first, GitHub Pages-ready casino/sports-style demo inspired by the provided visual references. It uses **virtual credits only** and has no deposits, withdrawals, payment processing, or real-money wagering.

## What changed
- 100 uniquely named games with different themes, rules, controls and game presentations.
- Futuristic neon UI, dark cards, lime accent, mobile-first navigation and game modal.
- Game families include slots, crash, wheel, dice, roulette, mines, blackjack, plinko, keno, penalty, vault/heist, treasure, runner, asteroid/shooter, memory, reaction, target and tower.
- Every game has an actual interactive round and balance/history updates.
- Favorites, search, category filters, virtual credit wallet and play history.
- No external assets or build tools required.

## GitHub Pages
Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the root of a GitHub repository. Enable GitHub Pages from the repository Settings and deploy from the main branch `/ (root)`.

## Important
This is a front-end demo. Outcomes are client-side and are not secure or suitable for real-money gaming.
